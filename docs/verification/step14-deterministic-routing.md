| 检查 | 结果 |
| --- | --- |
| 固定验收 | 基准S-A-B-T=660m/66s，阻断B-T后S-A-C-D-T=960m/96s；增幅45.454545…%，一位小数45.5% |
| 长度目标与速度 | 反向查询遵循无向边，长度最短优先；预计时间逐边累计，较快但较长的路线保持为备选 |

| 十进制精度 | 0.1+0.2与0.3按等长选字典序；0.1+0.20000000000000004保持略长；大/小数量级混合仍选实际最短路 |

模型从终点求最短距离，再沿最短距离条件逐点选取最小邻节点。正边权保证距离严格下降，长链重建无需在优先队列中复制路径前缀。内部十进制精度按权重数量级与节点数确定，输出有限浮点长度、时间和增幅。

性能环境：Windows 10 19045、Python 3.13.7，本机预解析NetworkOutput；100000节点、100000边，99999条链边加1条绕行边，两条结果分别含100000和99999个节点。计时包含图校验、邻接表构造、两次Dijkstra、字典序路径重建和指标计算。三次耗时1182.40、1257.34、1149.27ms，最大1257.34ms，低于2000ms；基准99999m，绕行99999.5m，路径长度和节点数逐次核对。
