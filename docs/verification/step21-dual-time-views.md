# 步骤21：双视图时间对比

2026-10-27。左右使用独立Cesium Viewer和时间状态，复制相同固定资产版本、显隐、透明度及顺序；相机双向同步六参数和场景模式。时间更新复用各自实体，退出对比卸载右侧地图、请求与计时，恢复单图宽度。

前端220项及生产构建通过。后端代码未变，沿用步骤19–20的383项结果。单元覆盖同步反馈、角度环绕、空目标、右侧固定版本/状态及独立时间、卸载请求、模式转换中的入口保护。

真实Edge验证：

- 左08:00、右09:00分别读取对应专题值，三份动态资产ID/version/visible/opacity逐项一致。
- 左、右各自鼠标拖动后，对侧相机同步；经纬度及方向差小于1e-7、相机高度差小于0.01米。
- 右侧切10:00显示缺测，左侧仍为08:00；左侧2倍播放不改变右侧时间。
- 时间变化期间源样例请求0次。退出后右侧组件isUnmounted=true，仅剩1个地图容器；重开二维对比，两侧scene_mode均为2d，再关闭后仍剩1个地图。
- 浏览器发现二维转换未完成就打开对比会由第二侧旧模式覆盖当前转换；入口现等待请求模式与已完成相机模式一致，再创建第二侧。
