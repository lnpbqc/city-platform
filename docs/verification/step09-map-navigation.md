# 步骤09：地图加载与导航验收

2026-10-26，在Windows、Edge、Node.js 24环境验证。前端15173、后端18000，使用独立SQLite和存储目录；真实数据库和发布文件保持原状。

| 检查 | 结果 |
| --- | --- |
| 前端回归 | 126项通过，类型检查与生产构建通过 |
| 固定版本 | 加载前查询asset_id@version并使用版本入口；失效版本保留服务code和trace_id |
| GeoJSON进度 | 流式读取实际字节，已知Content-Length显示百分比；下载后继续解析与贴地 |
| 三维进度 | 待下载、处理中数量来自Cesium事件；首批可见内容完成后标记已加载，六栋样例实际渲染 |
| 生命周期 | 旧版本、旧校区、已移除或卸载资源的晚到结果不重新挂载；旧请求取消，事件监听清理 |
| 默认地图状态 | 点图层关闭后刷新仍关闭；默认与自定义均通过统一目录状态接口保存 |
| 二维恢复 | 维港视角刷新后经度、纬度、高度、heading、pitch、roll误差均为0，二维模式与所选区域恢复 |
| 三维恢复 | 校区视角经纬高误差为0，方向浮点差小于2×10⁻¹⁵弧度；资源加载保持恢复视角 |
| 初始范围及复位 | 清空视角缓存后取校园白模范围；缩放和倾斜后复位，经纬高与初始值误差均为0 |
| 指北 | 从heading=3.6799712697弧度复位为北，位置与俯仰保持，Cesium返回2π时按等效0°显示 |
| 坐标/比例尺 | 实际拾取显示114.208917°、22.281739°、椭球高190.3m；比例尺500m，天空清空读数 |
| 区域快捷定位 | 维港、珠江新城和大学城入口均可飞到目标；校区选择刷新后保持 |
| 资源失败及重试 | 错误URL返回NOT_FOUND和服务端trace_id，卡片显示加载失败并可重试，地图保持可操作 |

浏览器核对发现即时setView及部分飞行结束时需要主动发布保存事件；已补充保存回调，并增加用例验证恢复视角不会被晚到资产覆盖。指针坐标随相机更新重新拾取，移出画布时清空。构建仍有Cesium体积提示；浏览器错误日志仅包含故意构造的404请求。

当前相机缓存属于本浏览器，完整场景、书签与URL复现分别按步骤13/22接入。在线影像和地形使用现有配置，离线时保持内置影像/椭球及资源错误提示。计数、单位和顺序控件按步骤10接入。
