# 步骤22：完整收藏与URL复现

完整画面保存为独立场景快照。收藏和地址记录场景ID/版本、运行ID、UTC时刻、小时/日分辨率、相机六参数及双视图右侧时刻。图层保持固定资产版本、加入状态、显隐、透明度和顺序；后续编辑生成新的地址快照，相机与时间变化直接更新地址参数。

## 实现与兼容

- `kind=scene`收藏保存完整状态；地区、点位收藏沿用原CRUD。收藏删除保留场景和运行。
- `GET /api/scenes/{id}?version=N`检查固定版本，版本不符返回409和trace_id。缺失场景、运行及不匹配的运行关联给出具体错误。
- 地图快照使用独立图层草稿，退出或浏览器返回普通地图后恢复原目录状态与相机。正在加载但已加入的图层按目标配置捕获。
- 仿真恢复先预检资产、路网和运行；固定运行的输入和结果与收藏场景各自保留。未知POST结果继续使用原幂等键，捕获等待提交确认完成。
- 场景中精确保存的旧图层绑定可读取原对象和时序，覆盖全局图层删除、换资产或换版本。未被场景保存的错误绑定保留原校验。
- 新地址取消旧恢复；无效地址保留错误及原画面。无时区链接按`Asia/Shanghai`解释，生成地址使用UTC。
