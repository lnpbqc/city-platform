- 按资产版本保存索引，UUID5包含资产ID、版本和原始Feature序号；重复原生ID、分页、重启及重建保持唯一且稳定。

- 无效历史数据保留资产并记录索引错误；新上传拒绝非有限坐标及自交面。不可用资产的目录计数为null，总对象统计只计可用当前版本。

## 万对象真实性能

工具：`map_back/tools/verify_object_queries.py`。隔离存储与数据库，独立uvicorn进程，动态回环TCP端口，httpx HTTP/1.1持久连接。使用10,000个混合点、线、面；上传文件1,625,231字节，上传、校验与入库共1604.31 ms。每种bbox预热后测100次，p95取升序第95个值，包含HTTP传输和JSON解码。

| 场景 | 命中总数 | 单页上限 | 中位数 | p95 |
| --- | ---: | ---: | ---: | ---: |
| 区域113.02,23.02,113.029,23.029 | 100 | 100 | 12.39 ms | 15.47 ms |
| 全范围-180,-90,180,90 | 10,000 | 100 | 35.91 ms | 40.37 ms |

区域首屏13个线或面跨越边界，核对后均已真实裁剪；两个场景的summary总数、类型分组和列表total一致，满足p95≤200 ms。测试结束后已关闭HTTP客户端、测试进程和日志，并清理临时资产目录。

复现命令（在`map_back`目录）：

```powershell
uv run python tools/verify_object_queries.py
```

原始测量JSON写入根目录`.verification/step08-performance.json`。
