# 步骤18：运行历史、固定重跑与路径回放

2026-10-27，使用隔离的SQLite/storage、后端18000、前端15173和真实Edge验证；原8000服务及实际数据保持。

## 实现

- 历史按场景ID、状态及北京时间范围筛选，每页20条；API使用UTC包含端点的范围。选择记录恢复固定请求、场景相机/图层、路网和结果，配置只读。“从历史编辑”复制为新的场景草稿。
- `POST /api/runs/{id}/rerun`原子复制旧快照、哈希和资产引用，创建新的run_id/trace/提交时间。场景后来修改或删除仍可使用。新建201、同key同哈希200、冲突409，旧模型当前不可执行返回409。沿用0010表结构。
- 回放按路径逐边length_m/speed_mps建立共用时钟，边内按时间插值；先到终点的标记停留。支持播放/暂停、拖动、节点到达时刻步进、0.5–8倍速与复位。不可达路线没有移动标记，同起终点为静止点。工作区切换、标签页隐藏及卸载时停止计时；地图复用两枚实体。
- JSON/GeoJSON下载使用服务端字节，错误保留code/trace。下载组件卸载取消请求，历史结果早于地图就绪时仍恢复移动标记。
