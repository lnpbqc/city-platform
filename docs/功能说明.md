# 功能说明

本项目是 Windows 本机单用户城市地图工作台，提供地图浏览、图层与文件管理、对象空间查询、专题时间对比和路网阻断推演。启动方式见[部署说明](部署说明.md)。

## 页面与地图浏览

顶部导航提供地图 `#/map`、我的数据 `#/data` 和仿真推演 `#/simulation`。直接打开数据页无需初始化地图；切换页面及浏览器前进、后退会保留已有地图会话。

首次进入地图显示广州大学大学城校区白模和合成点、线、面专题。地区面板支持全国省、市、区县级联与名称、行政代码搜索，并提供大学城、黄埔校区、香港维港和广州珠江新城快捷入口。

- 拖动、缩放、倾斜或使用工具栏调整视角；二维/三维切换、指北和复位位于地图工具栏。首次复位返回模型范围，手动选择地区后返回所选地区。
- 选择行政区后按需加载蓝色边界轮廓，可开关或重试。边界依赖网络，失败时仍可按本地参考点定位。
- 底部状态栏显示鼠标拾取位置的 WGS84 经纬度、椭球高及地面比例尺；指向天空时清空坐标。
- 普通地图的相机、模式与所选地区保存在浏览器。图层加入状态、显隐、透明度和顺序保存在后端，刷新和重启后恢复。

切换校区会更换内置数据，沿用默认图层的加入状态和样式；上传、外部登记图层保持各自的位置。数据来源及估计高度见[数据与模型说明](数据与模型说明.md)。

## 图层操作

左侧按底图、建筑、道路、水体、专题、仿真结果分组，支持折叠和名称筛选。每个图层提供定位、显隐、不透明度、下载和从地图移除；“添加图层”可重新加入内置或已登记资源。

已核对的二维图层可上移、下移，成功保存后刷新仍保持顺序。三维瓦片、拉伸白模和未知远端几何按深度显示。右下图例随可见图层更新，显示数据提供的颜色和单位；对象数量来自后端索引，未知计数显示为未知。

GeoJSON 下载单文件，内置或上传的三维数据下载完整 ZIP。外部 GeoJSON 下载依赖来源服务允许跨域；外部 3D Tiles 没有完整包时提供“打开数据源”。

## 数据管理

“我的数据”分为图层登记和资产目录。上传或登记后留在管理页，点击“加入地图”再加载。

### 上传与登记

1. 选择上传 GeoJSON 或 3D Tiles ZIP，填写名称、分类和来源。
2. 等待传输完成，再等待校验与发布；收到成功提示后，在登记列表中加入地图。
3. 检查位置、比例、朝向和属性，试用显隐及下载。上传包规范见[数据与模型说明](数据与模型说明.md)。

传输及校验期间可取消。HTTP 413 表示体积超限，422 表示格式、路径或元信息无效，页面显示具体原因。

外部资源通过 HTTP(S) 地址登记；后端保存元信息，浏览器从来源地址加载。来源服务需允许浏览器跨域读取。同一资产可以建立多份图层登记。

### 文件、登记与引用

| 操作 | 结果 |
| --- | --- |
| 从地图移除 | 停止当前图层显示，登记和文件保留 |
| 删除图层登记 | 删除该登记，资产文件保留，可从资产重新登记 |
| 删除上传资产 | 解除全部引用后，删除台账和本地文件 |
| 删除外部资产 | 删除台账，来源服务文件由来源方管理 |
| 删除默认资产 | 默认文件受保护，允许从地图移除 |

资产目录支持分页、关键词、类型、状态和时间筛选及体积排序。详情包含版本、SHA-256、范围、来源、坐标说明和逐文件清单；引用列表显示图层、场景和历史运行的 ID、版本及处理方式。

“扫描已有文件”刷新受管目录快照并补录文件。历史运行持续保护其固定的资产版本；删除场景或图层登记后，这些历史引用仍保留。顶部统计显示资产数、对象数、运行数、本地容量、类型分布和近七天新增，外部未知体积单独显示为未知。

## 对象查询

1. 打开“对象查询”，选择已加入的图层，按关键词和对象类型筛选。
2. 点击列表对象定位并高亮；点击地图对象会清除原查询条件、跳到对象所在分页并滚动到该行。
3. 查看稳定对象 ID、原始属性、来源和固定资产版本。未知高度、等级、置信度显示“未提供”。

“框选”按住左键拖动；“多边形”逐点点击后按“完成”。查询按真实几何相交与裁剪返回完整选择集，地图高亮全集，列表在同一集合内分页，统计显示计数、面积和已有高度范围。“清除范围”返回全层查询，Esc 或关闭面板取消绘制。

移除图层、切换校区或资产版本会取消当前绘制。普通 3D Tiles 以一个模型资源记录展示；有独立语义和几何的 GeoJSON 才能按要素查询。缺少空间几何的资源不参与范围选择，缺语义时显示“该瓦片未携带语义属性，来源：几何模型”。

## 时间轴与双视图

地图下方时间轴控制有时序快照的专题图层，支持小时/日、拖动、步进、复位、播放暂停及 1×/2×/5×。当前内置样例为北京时间 2026-10-25、26 日各 08:00 和 09:00 四个时次。

时间切换同步专题颜色、对象列表和选中详情。缺测显示“缺测”并隐藏对应专题实体；真实 0 使用独立颜色。逐日值按北京时间自然日，对已有非空小时值求均值；整日无值时显示缺测。静态建筑等资源保持原实例。

开启双视图后，两侧共享视角、图层和查询选择，时间与分辨率独立。左右任一侧操作相机时另一侧跟随，关闭后恢复单视图。对照状态可随完整工作区收藏保存。

## 仿真推演

### 配置与运行

1. 打开仿真页，选择固定路网版本、起点、终点和随机种子。
2. 点击地图道路或勾选正式边 ID 设置阻断；在“固定图层与状态”中选择场景图层及样式。
3. 创建或保存场景，保存内容包含当前相机、配置和固定资产版本。版本冲突时保留本地草稿，点击“读取最新场景”获取服务器版本。
4. 提交运行，查看 run_id、状态、输入哈希与诊断 ID。排队和运行中可以取消。
5. 成功后查看蓝色基准路径、橙色阻断后路径和红叉阻断边，以及长度、预计时间和绕行增幅。

提交响应丢失时，“重试同一次提交”复用原幂等键与输入，配置暂时锁定；确认后可通过“编辑配置”开始新草稿。

### 可复现示例

选择 `net-001@1.0.0`、起点 `S`、终点 `T`，分别保存配置并运行：

| 场景 | 阻断边 | 阻断后结果 | 与基准比较 |
| --- | --- | --- | --- |
| 正常 | 无 | S→A→B→T，660 米、66 秒 | 0% |
| 绕行 | B-T | S→A→C→D→T，960 米、96 秒 | +45.5% |
| 不可达 | S-A | 空路径，长度和时间未知 | 增幅未知 |

不可达属于计算成功的有效结果；同起终点返回 0 米、0 秒。该模型按显式边长度求无向最短路，时间按各边长度除以速度累计。路网为合成演示，含义见[数据与模型说明](数据与模型说明.md)。

### 历史、重跑与回放

“运行历史”按场景、状态和时间筛选，选择记录恢复固定输入、相机、图层与结果。“从历史编辑”复制为新场景草稿；“从历史重跑”使用原始快照和哈希创建新运行，原场景修改或删除后仍可重跑。

结果可下载为 JSON 或 GeoJSON。回放按逐边预计时间移动蓝、橙标记，支持播放、暂停、拖动秒数、节点步进、0.5～8 倍速和复位；先到达的标记停在终点，不可达路线没有标记。

## 收藏与画面复现

“收藏位置”保存地区或地图选取点。“收藏当前工作区”保存独立场景快照、固定图层版本、相机、当前时间和地图双视图状态，点击后恢复地图或仿真页。

“复制当前画面”生成带 `scene/run/t` 参数的链接。接收者需能访问同一前后端和资产服务；场景已删除或版本变化时，页面显示具体错误。删除收藏保留关联场景与运行，资产引用规则继续生效。

## 连接与错误诊断

服务中断时，顶部提示自动重连；“立即重连”可主动检查。恢复后刷新目录、列表、详情、时序和已知运行，同时保留筛选、分页、相机和本地草稿。

页面区分无数据、加载失败和无权限。“请求诊断”可复制 `code`、`message` 和 `trace_id`，用于与后端日志关联。处理方式见[部署说明](部署说明.md)。
