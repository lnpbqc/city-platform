# 功能说明

本项目是 Windows 本机单用户城市地图工作台，提供地图浏览、图层与文件管理、对象空间查询、专题时间轴和路网阻断推演。启动方式见[部署说明](部署说明.md)。

## 页面与地图浏览

顶部导航提供地图 `#/map`、我的数据 `#/data` 和仿真推演 `#/simulation`。数据页可独立打开。切换页面或使用浏览器前进、后退时，已打开的地图会话会保留。

首次进入地图显示广州大学大学城校区白模。地区面板默认列出已保存的展示区域，点击区域名称飞行定位。切换到「行政区定位」后可按省、市、区县逐级选择，按名称或行政代码搜索，或打开全国概览。

- 拖动、缩放、倾斜或使用工具栏调整视角；二维/三维切换、指北和复位位于地图工具栏。首次复位返回模型范围，手动选择地区后返回所选地区。
- 地图页右下角、仿真页右上角的底图卡片可切换影像、矢量底图，并分别勾选「显示注记」以显示道路名和地名。矢量注记默认开、影像默认关，刷新后恢复各自选择；注记需要天地图 Key，关闭注记不影响自有 POI 标签。
- 选择行政区后按需加载蓝色边界轮廓，可开关或重试。边界依赖网络，失败时仍可按本地参考点定位。
- 底部状态栏显示鼠标拾取位置的 WGS84 经纬度、椭球高及地面比例尺；指向天空时清空坐标。
- 图层加入状态、显隐、透明度和顺序由后端保存，刷新或重启后可恢复。

切换校区会更换内置数据，沿用默认图层的加入状态和样式；上传、外部登记图层保持各自的位置。数据来源及估计高度见[数据与模型说明](数据与模型说明.md)。

## 图层操作

左侧按底图、建筑、道路、水体、专题、仿真结果分组，支持折叠和名称筛选。每个图层提供定位、显隐、不透明度、下载和从地图移除；“添加图层”可重新加入内置或已登记资源。

已核对的二维图层可上移、下移，成功保存后刷新仍保持顺序。三维瓦片、拉伸白模和未知远端几何按深度显示。右下角图例显示可见专题的颜色分档和单位。对象数量来自后端索引。

普通地图的 3D Tiles 默认按模型原点对齐地表。无法识别原点时按原始高程显示，可在校准中选取模型贴地点。已保存的图层和场景继续使用原有的对齐方式、锚点与高度偏移。

GeoJSON 下载单文件，内置或上传的三维数据下载完整 ZIP。外部 GeoJSON 下载依赖来源服务允许跨域；外部 3D Tiles 没有完整包时提供“打开数据源”。

本地上传的 3D Tiles 可在图层卡片中选择「校准模型」。在三维视图拖动手柄或输入偏移和角度即可保存。贴地点和旋转中心可按需另选。「更新原资产」保存到原目录，引用该资产的图层、场景和仿真回放会读取更新后的模型。「另存为新资产」复制完整模型，可在「我的数据」单独登记。下载 ZIP 保留 `tileset.json` 及原有目录结构，包内写入落点的椭球高。

「道路显示到」默认第 2 级，可选第 1～4 级。放大后逐步显示所选等级内的细路。设置随图层状态和场景保存，仿真路径、起终点及阻断位置始终可见。

## 数据管理

「我的数据」依次显示图层登记、场景和资产目录，默认打开图层登记。

### 上传与登记

1. 上传 GeoJSON 或 3D Tiles ZIP，填写名称、分类和来源。格式及限额见[数据与模型说明](数据与模型说明.md)。
2. 传输完成后等待校验与发布。成功后在图层登记中点击「加入地图」，核对位置、比例、朝向和属性。

传输及校验期间可取消。HTTP 413 表示体积超限，422 表示格式、路径或元信息无效，页面显示具体原因。

外部资源通过 HTTP(S) 地址登记；后端保存元信息，浏览器从来源地址加载。来源服务需允许浏览器跨域读取。同一资产可以建立多份图层登记。

### 文件、登记与引用

| 操作 | 结果 |
| --- | --- |
| 从地图移除 | 停止当前图层显示，登记和文件保留 |
| 删除图层登记 | 删除该登记，资产文件保留，可从资产重新登记 |
| 删除上传资产 | 解除全部引用后，删除台账和本地文件 |
| 删除外部资产 | 删除台账，来源服务文件由来源方管理 |
| 删除默认资产 | 默认文件受保护，允许从地图移除 |

资产目录支持分页、关键词、类型、状态和时间筛选及体积排序。详情包含版本、SHA-256、范围、来源、坐标说明和逐文件清单；引用列表显示图层、场景和历史运行的 ID、版本及处理方式。

「扫描已有文件」可发现新增或改动的本地文件、复核校验和并补建索引。顶部统计显示资产数、对象数、运行数、本地容量、类型分布和近七天新增。外部未知体积显示为未知。

本地道路、POI 和普通平面 GeoJSON 自动生成显示数据，处理期间可继续浏览。失败时在图层卡片查看原因并重试。建筑拉伸和时序图层沿用各自的显示方式。资产详情显示原文件保留期限，并区分「下载上传原文件」和「导出 GeoJSON」。原文件到期后仍可导出、查询和编辑。保留条件见[部署说明](部署说明.md#geojson-完整快照与原文件保留)。

## 对象查询

1. 打开“对象查询”，选择已加入的图层，按关键词和对象类型筛选。
2. 点击列表对象定位并高亮，同时进入同一面板内的“对象详情”；点击地图对象也直接进入详情，并清除原查询条件、准备对象所在分页。
3. 查看稳定对象 ID、原始属性、来源和固定资产版本。未知高度、等级、置信度显示“未提供”。点击“返回查询结果”清除单对象选择，保留查询条件、范围、分页和列表滚动位置；范围查询的集合高亮保留。右上角关闭按钮关闭整个查询面板。

“框选”按住左键拖动；“多边形”逐点点击后按“完成”。查询按真实几何相交与裁剪返回完整选择集，地图高亮全集，列表在同一集合内分页，统计显示计数、面积和已有高度范围。“清除范围”返回全层查询，Esc 或关闭面板取消绘制。

移除图层、切换校区或资产版本会取消当前绘制。普通 3D Tiles 以一个模型资源记录展示；有独立语义和几何的 GeoJSON 才能按要素查询。缺少空间几何的资源不参与范围选择，缺语义时显示“该瓦片未携带语义属性，来源：几何模型”。

## 专题时间轴

加入时序图层后，地图下方显示紧凑时间轴，提供北京时间、粒度、步进、播放和进度拖动。展开可选择日期、小时或日、1×/2×/5× 播放速度，并查看时间范围与逐图层覆盖情况，或复位、刷新。收起时保留选时、播放状态及加载、缺测和错误摘要。点击错误摘要可查看详情。

地图工作台和仿真页共用时间轴。仿真页的「专题数据时间」独立于推演回放。展开状态仅在当前组件内保留。

时间切换同步专题颜色、对象列表和选中详情。缺测显示“缺测”并隐藏对应专题实体；真实 0 使用独立颜色。逐日值按北京时间自然日，对已有非空小时值求均值；整日无值时显示缺测。静态建筑等资源保持原实例。

旧双视图链接和收藏按原左侧视角及时间打开。

## 仿真推演

### 配置与运行

1. 打开仿真页，选择固定路网版本、起点、终点和随机种子。
2. 点击地图道路或勾选正式边 ID 设置阻断；在“固定图层与状态”中选择场景图层及样式。
3. 创建或保存场景，保存内容包含当前相机、配置和固定资产版本。版本冲突时保留本地草稿，点击“读取最新场景”获取服务器版本。
4. 提交运行，查看 run_id、状态、输入哈希与诊断 ID。排队和运行中可以取消。
5. 成功后查看蓝色基准路径、橙色阻断后路径和红叉阻断边，以及长度、预计时间和绕行增幅。

提交响应丢失时，“重试同一次提交”复用原幂等键与输入，配置暂时锁定；确认后可通过“编辑配置”开始新草稿。

### 可复现示例

选择 `net-001@1.0.0`、起点 `S`、终点 `T`，分别保存配置并运行：

| 场景 | 阻断边 | 阻断后结果 | 与基准比较 |
| --- | --- | --- | --- |
| 正常 | 无 | S→A→B→T，660 米、66 秒 | 0% |
| 绕行 | B-T | S→A→C→D→T，960 米、96 秒 | +45.5% |
| 不可达 | S-A | 空路径，长度和时间未知 | 增幅未知 |

不可达是有效计算结果，同起终点返回 0 米、0 秒。路网和算法见[数据与模型说明](数据与模型说明.md#路网与结果含义)。

### 历史、重跑与回放

“运行历史”按场景、状态和时间筛选，选择记录恢复固定输入、相机、图层与结果。“从历史编辑”复制为新场景草稿；“从历史重跑”使用原始快照和哈希创建新运行，原场景修改或删除后仍可重跑。

已结束的运行可在列表中确认删除，清除输入快照、结果和日志，并释放该运行的资产引用；排队或运行中的任务需先取消。被已保存场景或收藏引用时，页面列出引用来源，解除引用后再删除。删除当前查看的运行会清除结果和回放，保留场景配置；源数据不会删除。

仿真路径以连续折线显示，原始路段仍可点击设置阻断。默认只标注起终点及阻断位置的相关节点。历史中的图层登记删除后，只要固定资产版本仍存在，仍可恢复历史画面。

结果可下载为 JSON 或 GeoJSON。回放按逐边预计时间移动蓝、橙标记，支持播放、暂停、拖动秒数、节点步进、0.5～8 倍速和复位；先到达的标记停在终点，不可达路线没有标记。

## 收藏与画面复现

“收藏位置”保存地区或地图选取点。“收藏与链接”中的“收藏当前画面”保存独立场景快照、图层配置、相机和当前时间，点击收藏后恢复地图或仿真页。

普通浏览在本机保存地图的相机、二维或三维模式及地区，并单独记住仿真相机。打开分享链接时优先恢复链接内容，保留原地址。

地图工作台的“复制视图链接”只带相机和地区。接收方使用自己的图层配置和默认时次，复制操作无需保存场景。仿真页的“复制复现链接”分享完整场景、运行、时间和相机。已有完整链接继续按固定场景和版本恢复。

在“我的数据 → 场景”按名称或场景 ID 查找、打开或删除场景。文件资产详情中的“管理此场景”可直接查找该引用。删除场景会使对应复现链接失效。场景有收藏时先在“收藏与链接”解除收藏，历史运行及其资产引用会继续保留。

## 连接与错误诊断

服务中断时，顶部提示自动重连；“立即重连”可主动检查。恢复后刷新目录、列表、详情、时序和已知运行，同时保留筛选、分页、相机和本地草稿。

页面区分无数据、加载失败和无权限。“请求诊断”可复制 `code`、`message` 和 `trace_id`，用于与后端日志关联。处理方式见[部署说明](部署说明.md)。
