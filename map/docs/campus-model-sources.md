# 广州大学双校区三维模型来源核查

核查日期：2026-10-22。范围为大学城校区和黄埔校区。仅核查公开资料，没有联系第三方、购买模型或把候选模型加入应用。

## 本轮结论

已取得两个校区的 OpenStreetMap 建筑轮廓，可用于生成带来源说明的简化白模。尚未找到可直接下载、校园覆盖和开放使用许可均明确的完整贴图模型或 BIM 模型；这表示本轮公开检索未取得，并不表示模型不存在。

真实模型有两条值得优先核实的线索：校内已有数字孪生智慧校园相关工作；黄埔校区建设项目有官方记录的 BIM 应用成果。这些报道不构成模型文件的开放授权。

## 可用的建筑轮廓

当前应用已修复组合建筑遗漏：大学城135条记录（117个way、18个relation，52条有原始高度、83条高度估计）；黄埔27条记录（26个way、1个含两个独立部件的relation，全部高度估计）。组合外环不重复生成独立对象，内庭院保留为空洞；支持 Polygon / MultiPolygon。按外环顶点或参考中心落入校园边界筛选，不能据此认定校园已完整覆盖。本轮快照中另一个缺少完整成员的组合建筑位于邻校范围，未纳入。

统计方法为选择带 `building` 标签的 way，以其节点经纬度算术平均位置是否落在校园 outer 环内筛选。本轮没有把 multipolygon relation、building:part、重叠对象和实地建筑一一核对，因此 **118 和 28 是该方法得到的 OSM way 数，不是完整建筑总数或完整率**。高度与楼层统计是标签存在数，不等于已核验有效高度。OSM 高度也不是本项目的实测结果。

快照与统计保存于：

- [大学城原始数据](research/university-town-osm-20261022.json)、[大学城统计](research/university-town-coverage.json)
- [黄埔原始数据](research/huangpu-osm-20261022.json)、[黄埔统计](research/huangpu-coverage.json)

这些数据提供平面几何和部分名称、楼层或高度属性，不提供建筑外立面照片贴图。白模应分别标注原始高度、楼层推算高度和默认估计高度；不得把统一拉伸高度描述为实测校园模型。黄埔校区高度标签缺失更明显。

OSM 数据采用 ODbL，使用时需展示 OpenStreetMap contributors 署名及许可入口，分发衍生数据库需遵循对应许可条件。详见 [OSM 官方版权与许可](https://www.openstreetmap.org/copyright)。

## 真实 BIM 与校园模型线索

### 黄埔建设项目：存在 BIM 成果，未取得公开模型包

中国施工企业管理协会的第四届工程建设行业 BIM 大赛结果，在一等成果序号 90 列出广州大学黄埔研究院建设项目 EPC 全生命周期 BIM 应用，参赛单位为中国建筑第六工程局有限公司、广州市市政工程监理有限公司、广州昊俊驰骋科技有限公司。[正式结果附件](https://www.cacem.com.cn/uploadfile/file/20230721/1689929956863535.pdf)、[此前公示附件](https://www.cacem.com.cn/uploadfile/file/20230714/1689324652177154.pdf)。

广州市住建部门公布的智慧城市与新城建应用场景清单，第 14 页序号 97 也列出该项目及中建六局，说明采用 BIM 团队制作施工工序动画等。[官方清单](https://zfcj.gz.gov.cn/attachment/7/7763/7763563/10121937.pdf)。

这能支持“项目存在 BIM 应用和相关模型制作”的判断，不能据此确认全校最终交付模型范围、现状准确性、文件格式、地理配准或对外共享权。核查页面没有提供可直接使用的模型下载入口或开放许可证。若向校方申请，可由基建或黄埔校区管理方核实交付成果，再确认上述参建方的数据权属和可共享范围。

黄埔研究院与当前黄埔校区的对应关系，可由校方新生指引核对：高德搜索广州大学黄埔研究院、百度搜索广州大学黄埔校区，均指向知明路 72 号。[校方指引](https://hp.gzhu.edu.cn/info/1169/2015.htm)。具体楼栋名称与投用情况应以校方资料为准，不由 OSM 反推。[校区服务指南](https://hp.gzhu.edu.cn/info/1169/1985.htm)。

### 校内数字孪生智慧校园：值得优先询问的现有工作

校方 2024 年报道记载郝洪院士展示土木工程在本校数字孪生智慧校园中的应用；2025 年研究生院相关报道再次提及本校数字孪生智慧校园。[2024 校方报道](https://news.gzhu.edu.cn/info/1002/27147.htm)、[2025 研究生院报道](https://yjsy.gzhu.edu.cn/info/1038/108931.htm)。

建议优先向校内工程抗震研究中心相关团队了解是否已有可共享的校园建筑模型、地理底座或可浏览平台。公开报道没有给出覆盖哪个校区、模型格式、下载链接和复用授权，不能据此承诺已获得完整校园模型。

### 大学城历史三维项目

2014 年 GIS 软件开发竞赛的官方获奖名单包含中山大学地理科学与规划学院的广州大学城三维仿真模拟作品，指导老师为马林兵。[赛事官方名单](https://contest.geoscene.cn/detail/37)。

这是大学城范围的历史项目线索，名单没有证明其完整覆盖广州大学校区，也未提供模型文件或开放授权；年代较早，现状一致性仍需核查。

## 付费模型候选

[CG 模型网编号 466332](https://www.cgmodel.com/model/466332.html) 名为广州大学城学校片区，页面列出 3ds Max 2016、V-Ray 4.2，压缩包约 1.30 GB。它可作为供应商核实对象，但尚未确认真实校园覆盖、建模年代、坐标或网络应用分发权，不能当作已找到的广州大学实景模型。

它也不是当前应用可直接上传加载的数据：现有上传入口接收不超过 100 MB 的 3D Tiles ZIP；该候选是大型 `.max` 工程，需要导出、材质整理、减面、地理配准和切瓦片。Cesium 官方支持将 OBJ、FBX 等通用模型转换为 3D Tiles，具体转换能力见 [Cesium 数据格式说明](https://cesium.com/learn/3d-tiling/tiler-data-formats/)。购买前需先要求供应商确认目标建筑和授权范围。

## 后续接入应核对的最少信息

1. 校区与楼栋覆盖、采集或设计版本，以及是设计模型还是现状模型。
2. 文件格式、完整贴图、大小；优先获取可直接发布的 3D Tiles，否则另行转换。
3. 坐标系、水平和高程基准、单位、定位点与朝向，避免把局部坐标模型直接放到地球上。
4. 浏览器展示、离线保存、转换与团队共享的许可；有原文件不代表可以公开分发。
5. 实际加载后核对几处建筑的位置、朝向与尺度，再标记为已验证模型。

2026-10-22 后续接入：用户确认先用真实轮廓白模后，已将上述两个校区轮廓生成 `public/samples/{校区}/campus-buildings.geojson` 并默认展示；随后补读组合建筑，修复遗漏的教学和实验楼。高度依据和来源属性可查询，六栋合成瓦片仍保留为可选上传样例。白模未取得真实立面贴图。实施与验收见 [校园白模待办](../../待办/待办-校园轮廓白模接入.md)、[建筑漏项修复](../../待办/待办-校园白模建筑漏项.md)。
