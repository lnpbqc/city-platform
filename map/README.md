# 城市韧性地图前端

Vue 3 + TypeScript + Vite + CesiumJS。中文浅色地图工作台，使用原生 Vue 状态与独立地图控制器，无额外 GIS 框架。

实测界面见 [大学城校区（默认）](docs/campus-university-town.png)、[黄埔校区](docs/campus-huangpu.png)、[全国地区定位](docs/region-picker.png)、[行政区边界高亮](docs/boundary-highlight.png)、[独立数据管理](docs/data-manager.png)、[文件删除确认](docs/data-delete-confirm.png)。

## 开发

```powershell
pnpm install --store-dir ..\.pnpm-store
# 首次配置；若已有 .env.local，不要覆盖。
Copy-Item .env.example .env.local
# 编辑 .env.local，填写 VITE_CESIUM_ION_TOKEN
pnpm dev --port 5173 --strictPort
```

默认打开 <http://127.0.0.1:5173/>。Token 为浏览器可见配置，使用拥有所需影像和地形权限的 ion 读取 Token；本地配置由 `*.local` 忽略规则排除。服务重启后读取修改后的环境变量。缺少 Token 时使用打包的低分辨率地球影像；配置 Token 后会请求 ion 影像与世界地形，失败显示提示并保留可操作的本地图层。

后端在同级 `map_back/`，启动说明见 [项目入口](../README.md)。前端开发及预览均代理 `/api`、`/data-files` 到 `http://127.0.0.1:8000`。后端不可用时仍可浏览内置小样；点击图层面板底部刷新按钮可重连。

```powershell
pnpm test
pnpm build
pnpm preview --port 4173 --strictPort
```

Node.js 24 内置测试运行器检查加载竞态、登记与资产操作，使用实验性的模块替身 API，无额外测试框架。管理页入口脚本约 118 KB（gzip 约 44 KB），地图模块按需加载，包含完整 Cesium，约 4.21 MB（gzip 约 1.13 MB），仍会触发 Vite 体积提示。

## 代码边界

- `src/App.vue`：协调 `#/map` / `#/data` 导航、共享登记目录、管理对话框和加入地图事件。地图视图按需挂载，之后通过显隐保留实例。
- `src/components/MapWorkspace.vue`：地图会话、当前地区与行政边界、地图图层及浏览工具；返回地图时恢复尺寸与渲染。
- `src/components/DataManagerView.vue`：独立数据管理视图，包含登记列表、本地文件、详情和删除确认；`LayerChooser` 用于重新加入内置或已有图层。
- `src/composables/useLayerCatalog.ts`：图层目录、后端状态、登记保存/移除及加载联动；Cesium 实例通过回调访问，不进入 Vue 深层响应式对象。
- `src/components/`：`WorkspaceHeader` 导航、`MapCanvas` 地图生命周期、`LayerPanel` 分类与筛选、`LayerItem` 单图层操作、`RegionPicker` 地区选择、`MapToolbar` 浏览工具、`FeatureInspector` 属性、`MapLegend` 图例，以及状态、反馈、帮助和上传组件。模板与私有 `scoped` 样式在同一个 `.vue` 文件。
- `src/mapController.ts`：Cesium 实例、资源生命周期、加载/移除、显隐/不透明度、定位和属性拾取。异步完成时核对请求身份，防止旧数据重新加入已移除的图层。
- `src/regionBoundary.ts`：行政区边界请求、坐标转换与轮廓提取；边界控件及其私有样式位于 `RegionPicker.vue`。
- `src/api.ts`、`src/types.ts`：后端请求、共同图层约定及内置小样目录。
- `src/style.css`：全局基础样式、通用控件、设计变量和通用动效，不再包含面板布局。Cesium 自建 DOM 样式使用 `MapCanvas` 中的 `:deep()` 明确定位。

Cesium Workers、ThirdParty、Assets、Widgets 由 `vite-plugin-static-copy` 映射到 `/cesium/`。当前插件 4.x 保留源目录，配置通过 `stripBase: 4` 去掉 `node_modules/cesium/Build/Cesium`；开发和构建预览使用相同路径，不能让这些请求落到 HTML 回退页面。

## 全国地区定位

地图上方地区按钮提供省/市/区县级联、中文名称和行政代码搜索、全国概览，以及香港维港、广州珠江新城、广州大学大学城/黄埔校区快捷入口。首次打开大学城校区；已有本地视角时恢复所选地区与相机。搜索可输入 `广东 广州 天河`，重名区县显示完整上级路径。标签表示所选定位目标，拖动地图保持该标签。

地图工具支持缩放、倾斜、二维/三维切换和指北。首次加载校园白模后按其空间范围取景，复位回到该范围；手动选择地区后复位返回所选地区。指北保留当前相机位置与俯仰。鼠标状态栏显示WGS84经纬度和拾取表面的椭球高，天空处清空读数；比例尺按画面底部100像素对应的地面椭球距离计算，显示1/2/5级别长度。

`public/data/regions.json` 是 [DataV GeoAtlas 目录](https://geo.datav.aliyun.com/areas_v3/bound/all.json) 的本地快照，共 3,238 条。按行政代码纠正省直管县的源类型后，为 34 个省级、333 个市级、2,870 个区县级条目，加 1 个国家条目。直辖市及港澳没有虚构市级；省直管县可直接从省级选择。源目录只提供台湾省级条目，界面明确提示无下级目录。

快照记录抓取时间、源 SHA256 和坐标说明。按 [DataV 坐标说明](https://help.aliyun.com/en/datav/datav-7-0/user-guide/map-data-format-1)，目录参考点通过 `coordtransform`（MIT）近似转换到 WGS84；台湾点保持不变。参考点仅用于相机定位，目录与搜索可离线使用；行政区定位不会移动、清除或按地区自动筛除图层。

选择省、市、区县或全国概览后，默认按需请求 `https://geo.datav.aliyun.com/areas_v3/bound/{行政代码}.json`，以蓝色贴地轮廓高亮当前地区，并按完整边界范围取景。支持 Polygon、MultiPolygon、离岛和内环，不铺面以保留区域内用户对象的点击查询。轮廓按同一坐标约定近似转换到 WGS84（台湾省级边界保持不变），仅用于浏览参考，不用于精确勘界或面积统计。

地区按钮下方可开关高亮，显示加载状态并在失败后重试。单独开关或重试不改变相机。边界需要联网，服务不可用时仍可按本地参考点定位；请求 20 秒超时。切换地区会清除旧轮廓并取消旧请求，返回校区小样时清除行政边界。边界是会话内的定位辅助，不写入登记、图层计数或“我的数据”，也不转换用户上传数据。

需要更新快照时，在本目录联网运行 `node scripts/update_regions.mjs`，然后执行 `pnpm test` 和 `pnpm build`。这只更新地区定位参考点，不转换用户上传的 GIS 数据。

## 小样与接入

`public/samples/university-town/` 与 `public/samples/huangpu/` 各提供公开轮廓校园白模、三个合成点线面 GeoJSON，以及一个含六栋合成建筑的 3D Tiles 1.1 数据集和 ZIP。默认加载校园白模与合成点线面；六栋瓦片样例通过“添加图层 → 内置示例”按需加入。快捷切换只更新内置数据；已移除的内置图层不自动重新加入，保留显隐与透明度，用户上传/登记资产保持原位置。左侧图层卡片的下载随当前校区切换。原 `/samples/water-points.geojson` 等公共地址保留为默认大学城校区的兼容副本。

校园白模为 `campus-buildings.geojson`，基于 2026-10-22 保存的 OpenStreetMap 官方 API 快照，按校园边界筛选独立建筑和组合多边形，并去重组合外环：大学城 135 条建筑记录（117 个 way、18 个 relation），黄埔 27 条（26 个 way、1 个双部件 relation）；不是完整建筑总数，不包含真实立面贴图。多部件建筑及其庭院内洞保留。大学城 52 条采用 OSM 高度标签（未经本项目核验），83 条高度估计；黄埔27条全部为估计。估计规则为楼层数 × 3米，没有有效高度和楼层时统一9米。点击建筑可查询名称、高度依据、原始高度/楼层、OSM 链接和版本。轮廓无坐标偏移转换，采用 OSM WGS84；地形决定显示基底，不表示已验证测绘高程。

数据使用 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)，地图显示 © OpenStreetMap contributors；每个校区附 `campus-buildings-LICENSE.txt`。下载、修改或分发数据时保留来源与许可。模型来源与筛选方法见 [来源核查](docs/campus-model-sources.md)。后续取得真实贴图/BIM 模型后可另行登记，不把本白模当作精细模型。

相机与合成样例生成脚本共用 `src/data/campuses.json` 的 WGS84 参考点：大学城 `[113.366746,23.043612]`，黄埔 `[113.570902,23.310314]`。大学城参考 [高德校区点](https://amap.com/place/B00140AM0Y) 的 GCJ-02 坐标近似转换；黄埔参考 [OSM way 1191052293](https://www.openstreetmap.org/way/1191052293) 的 WGS84 范围中心，并按 [校方服务指南](https://hp.gzhu.edu.cn/info/1169/4055.htm) 核对校区名称与知明路72号地址。两者仅用于浏览，不绘制虚构校园边界。合成瓦片放置高度为示意值，其属性及合成点线面均明确标注数据性质。

2026-10-22 浏览器实测默认大学城及黄埔往返切换，两个校区四类图层均已加载、卡片下载入口与当前小样一致，控制台无warn/error。黄埔校区当前 ion 底图仍显示较早的施工期影像，不能将底图时效或合成建筑视为校园现状。

可重新生成：

```powershell
python scripts/generate_samples.py
# 从已保存 OSM 快照离线生成白模，不会重新联网或改动合成瓦片。
python scripts/generate_campus_buildings.py
python -m unittest discover -s scripts -p test_campus_buildings.py
```

GeoJSON 采用 WGS84 经纬度。普通点线面按地形贴地展示，不投射到建筑表面。多边形要素可通过数值属性 `map_extrude_height_m` 指定相对地形的拉伸高度（米，0 < 高度 ≤ 1000）；缺失或非法值保持普通面。透明度沿用现有图层控件。下载白模重新登记或上传时，来源填写 `OSM / OpenStreetMap`，以显示对应署名；高度和来源属性随文件保留。3D Tiles 必须自带地理配准，未配准 GLB、`.max` 和任意模型文件不能作为瓦片上传。

白模接入及组合建筑漏项修复已通过36项前端测试、5项生成测试、类型检查及生产构建；测试覆盖真实教学楼回归、多外环、庭院内洞、环方向与重复外环排除。浏览器验证两个校区、对象高度依据、90%不透明度、显隐、定位、移除重加与视图往返。截图：[大学城白模](docs/campus-white-university-town.png)、[黄埔白模与高度依据](docs/campus-white-huangpu.png)。

白模先等待地形提供者就绪，再由 `src/buildingTerrain.ts` 采样建筑边界和内部网格，排除真实庭院。顶面采用最高采样高程加高度参数，底面延伸到最低采样高程以下0.1米，使用固定椭球高程的封闭体积，避免依赖单个中心点的实时偏移。普通面仍贴地并只分类地形；场景保留地形深度测试。在线地形采样失败会显示图层错误，可重试；无在线地形时按椭球基准放置。采样会增加白模首次加载时间，加载中移除不会在完成后重新挂载。原始高度参数与缺测标注不变，展示基底不等于测绘高程。

俯仰按钮围绕画面中心地面点改变观察角度，保持距离与朝向；点标记采用底部锚定的圆形图标，参与正常深度遮挡。复核发现的数据缺口和修复记录见 [校园白模复核](docs/campus-model-audit.md)。

添加方式：

- **内置静态图层**：数据位于 `public/`，在 `src/types.ts` 的小样目录登记相对地址。
- **持久登记地址**：页面填写 HTTP(S) 数据地址，后端仅保存元信息；远端需允许浏览器跨域请求。登记本机静态文件也应使用其 HTTP 地址。
- **上传文件**：GeoJSON ≤10 MB，3D Tiles ZIP ≤512 MiB，解压总量 ≤2 GiB；后端校验后返回文件地址，再由相同的 Cesium 加载流程消费。

地图从`GET /api/layers/catalog?campus=...`读取底图、默认与自定义资源，保留固定资产版本、加入状态、显隐和不透明度。加载前查询`GET /api/assets/{id}/versions/{version}`，使用该版本入口；缺失版本或资源错误显示code与trace_id，并可重试。GeoJSON显示实际下载字节与百分比，传输完成后继续解析和贴地；3D Tiles显示待下载/处理数量，首批可见内容完成后显示已加载。移除或切换资源会取消旧请求并丢弃晚到结果。

默认与自定义图层状态由后端保存，切换校区共享默认图层状态并更换对应资产版本。刷新或重启服务后恢复已加入图层；旧登记升级后首次手动加入一次。相机经纬高、heading/pitch/roll、二维/三维模式及所选地区保存在浏览器`city.map.view.v1`，刷新后恢复；加载资源保持已恢复视角，损坏或不可用缓存回到默认校区。三维对象只展示数据已有的属性。

## 图层树、图例和顺序

左侧固定显示底图、建筑、道路、水体、专题、仿真结果六类分组，支持折叠与名称筛选；空组显示“暂无已加入图层”。逐层对象数来自服务端索引，与`/api/objects`的total一致；未知计数显示“对象数未知”，普通3D Tiles显示模型资源数。

右下图例展示可见且加载完成的图层，条目、颜色与单位使用目录的legend/unit。缺失字段显示“未提供图例”或“单位未提供”，隐藏图层同步移出图例。

已核对的二维层提供上移/下移，跨分组调整相邻二维层的全局叠加位置，较小的叠加序更靠前显示。保存成功后读取服务端原子重排的目录，刷新保持顺序；保存失败保留原顺序与原因，可再次点击重试。新增登记后自动刷新目录，顺序元数据未齐时禁用排序。贴地面/线使用zIndex，点使用数据源集合顺序；瓦片、拉伸面、带Z坐标和未知远端几何保持深度绘制并关闭排序入口。

## 仿真推演

仿真页`#/simulation`复用地图组件，场景配置与普通地图目录状态分别保存。可选择固定路网版本、起终点、阻断边及seed；地图道路/红叉与边列表同步。保存场景包含相机、固定资产版本、加入/显隐/透明度，刷新读取上次场景；If-Match冲突显示409及trace_id并保留草稿，用户可显式读取最新场景。

提交期间锁定配置，重复点击只发送一次运行请求；响应丢失后重试保留同一key/body并跳过再次保存场景。队列状态每500ms读取，运行中可取消；页面显示run_id、模型/场景版本、输入哈希及原trace。成功后按快照网络绘制蓝色基准路径、橙色阻断后路径及红叉，地图保留深度遮挡；结果区显示长度、逐边预计时间、增幅及节点序列。net-001的B-T阻断显示660/960m、66/96秒和45.5%。编辑配置清除当前结果展示，后端历史结果保持。

右上“运行历史”按场景ID、状态和北京时间范围筛选，每页20条。选择记录恢复固定输入及场景相机/图层；“从历史编辑”创建新的草稿，“从历史重跑”调用旧快照生成新run_id、保留输入哈希和版本，原场景后来修改或删除均可使用。重跑响应未知时，“重试同一次提交”复用原目标和幂等键。

结果区的JSON/GeoJSON按钮下载服务端结果。预计时间回放按每条边的length_m/speed_mps移动蓝/橙标记；共用时钟，先到终点的标记停留。提供0.5–8倍速、播放/暂停、秒数拖动、节点到达时刻步进及复位；切换工作区、标签页隐藏和卸载时停止计时。不可达路线没有移动标记，同起终点停在原点。回放为合成位置插值，时间来自路网显式权重。

## 专题时间轴

两校区现有积水点、道路流量及积水面接入四个合成时次：北京时间2026-10-25、26日08:00/09:00。时间轴支持逐小时精确查询、逐日均值、拖动/步进/复位和1×/2×/5×播放；每秒推进一个所选分辨率的时次。缺测对象隐藏，列表与详情显示“该时次缺测/未覆盖”；真实0独立着色。日均按Asia/Shanghai当天已有非null小时值计算，点/面单位cm，道路单位辆/小时。

时间变化只读取固定版本专题值并更新已有实体，静态图层保持原资源。选中对象的列表/详情同步time/resolution，原属性单独保留；暂停、离开工作区、标签页隐藏及卸载时停止计时。快速切换取消旧请求，失败清除旧帧并显示code/trace，点击时间轴刷新重读。

“双视图时间对比”沿用当前固定资产版本、显隐、透明度和顺序，右侧初始显示范围中最后一个时次。左右各自控制小时/日、播放及缺测，拖动任一地图会同步两侧相机；二维/三维模式保持一致。模式转换完成后可打开对比，退出时释放第二侧Viewer、未完成请求和计时，单图保留当前视角与时间。

## 位置收藏与图层恢复（2026-10-23）

地区选择器旁的“收藏位置”支持收藏当前地区、地图点击选点、重命名及删除。收藏保存在服务器，同一工作台的浏览器共享。点位采用 WGS84 经纬度，按 Esc 或取消退出选点；点击收藏地区使用目录默认范围，点位使用三维、俯仰 -60°、距离 1000 米的视角。位置收藏保存地区或点位；当前视角由上述浏览器缓存恢复，完整场景收藏按步骤22接入。

自定义图层加入、移除、显隐变化立即保存，透明度防抖 300 毫秒；保存失败显示“地图状态未保存”和重试入口。自动恢复失败保留已加入状态及加载重试入口。修改数据地址或类型后需重新加入，删除登记不删除文件。地区目录失败可重试，收藏仍保留。

升级前在后端执行 `.\.venv\Scripts\python.exe -m alembic upgrade head`，然后重启后端并刷新页面。验收截图见 [收藏与重启恢复](docs/bookmarks-persistence-verification.jpg)。

本轮前端 78 项、后端 80 项测试及类型检查、生产构建通过。真实停止并重启后端后，地区及点位收藏保留，自定义图层自动恢复隐藏及 40% 不透明度。临时收藏已清理，原有登记和 4 个发布文件 SHA-256 保持一致。

## 登记、地图与本地文件

顶部“我的数据”是独立管理页。上传、登记和编辑成功后留在管理页；仅“加入地图 / 查看地图”切回地图并加载或定位。地图左侧的“全部 / 自定义”仅筛选当前已加入图层，包括隐藏、加载中和加载失败的对象。移除后可通过“添加图层”重新加入；此处不提供登记或磁盘删除。

登记与本地文件分别管理：删除登记会移除当前地图对象，保留上传目录；同一文件资产可被多个登记复用。名称、分类和来源修改不会重置地图样式，地址或类型变化会卸载旧对象并提示重新加入。

“资产目录”按服务端分页显示资产，支持类型、状态、时间、关键词筛选及体积排序。详情包含版本、SHA-256、WGS84范围、坐标说明、来源和逐文件校验和。顶部显示数量、容量、类型分布及滚动7天新增；扫描已有文件更新目录快照。未知外部体积显示“未知”，默认文件受保护，外部资产只移除登记。

上传对话框显示传输百分比；传输完成后显示校验与发布，收到成功响应再关闭。传输和校验期间均可取消。新外部地址保存资产名称、来源与坐标说明；同地址可以复用资产建立不同图层登记。3D Tiles以完整发布目录管理，卡片下载保留所有相对路径。

彻底删除必须先解除所有登记引用；确认框列出名称、文件数、体积和不可恢复说明，后端还会重新检查引用。文件先进入不公开的删除暂存区再清理，失败会保留错误状态并允许重试。外部地址与内置示例不参与本地磁盘删除。

`#/map`、`#/data` 支持直接打开与浏览器前进/后退；切换视图保留当前相机、边界、图层显隐及透明度。直接进入管理页无需初始化 WebGL；地图无法启动时仍可管理数据。

2026-10-22 已完成浏览器与本机 API 联调：临时 GeoJSON 上传后留在管理页、加入/移除/重新加入地图、编辑名称、引用时禁止删除、删除登记保留文件、从文件重新登记、彻底删除及文件地址 404。天河区视角、行政边界、隐藏状态和 95% 透明度在页面切换及前进/后退后保持；刷新直达管理页正常。临时资产已清理，原有两份资产的三个文件 SHA256 与迁移前备份一致。详细记录见 [数据管理验收](../待办/待办-数据管理与实体文件.md)。

## 图层下载（2026-10-23）

下载按钮位于左侧每张地图图层卡片的操作行，帮助面板只保留操作说明和来源许可。GeoJSON 下载对应文件；内置三维小样下载所属校区的 ZIP；本地三维资产通过 `GET /api/assets/{id}/download` 下载完整发布目录。外部 GeoJSON 通过浏览器直接读取并下载，需要服务允许跨域；外部 3D Tiles 未提供完整包时显示“打开数据源”。下载失败在对应卡片提示，可重试，不影响地图中的其他图层。

上传成功仅完成文件保存及登记，不自动加载。点击“加入地图”后才加载、定位。GeoJSON 必须是 WGS84 的 FeatureCollection，普通面默认平铺，白模拉伸需要数值属性 `map_extrude_height_m`；3D Tiles 上传自包含且已地理配准的 ZIP（含 tileset.json、模型及贴图），无需更改前端代码。

本轮通过48项前端测试、51项后端测试、类型检查及生产构建。浏览器下载点位文件与源码 SHA-256 一致；下载两类三维 ZIP 均保留清单与模型，临时上传资产已清理；黄埔白模下载为27条记录。截图见 [卡片下载与帮助](docs/layer-download-help.jpg)。
